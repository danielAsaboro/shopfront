This public demo isn't connected to Ring: its door events are generated and its one delivery alert is a replay. On a shop's own Shopfront, connecting Ring is what makes the receiving desk real.

What connecting does

  • Shopfront reads the doorbell's Event History for each day: motion, doorbell presses, and Ring's person and package alerts.
  • With Amazon Bedrock on, it downloads the camera frame of a door event near an order or a carrier's scan and asks Bedrock who it shows.
  • It accepts Ring's signed webhooks, so Ring's package alerts reach the receiving desk.
  • It reads from Ring and changes none of the doorbell's settings; the token stays on the shop's computer and never reaches the browser.

How an owner connects (Ring Developer Playground)

  1. Open the Ring Developer Playground and click Generate Token.
  2. On Shopfront's own Connect Ring page, paste the access token. It lasts about 30 minutes.
  3. Press a scene in the Playground. Shopfront shows frames for door events filed after the token was issued.

Which calls to Ring's API have been captured live so far (each with Ring's X-Request-ID), and what hasn't been captured yet, is listed in the repository's evidence/README.md; the proof table is in docs/status.md.
